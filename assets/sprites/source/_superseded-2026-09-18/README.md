# Superseded art — the first design (2026-09-18)

The **goggled Scout Bat** and the **caped Brute Bat**, Lewis's first PixelLab
drawings. They are kept because they were real work and because the sheets
built from them can be rebuilt from here, but **they are not the design any
more.**

Lewis replaced them in homework **B4** on 2026-09-19: hand-drawn, a large
circle body, wings, ears and a mouth, no legs, black and white. That is what
lives in the folders above this one.

Nothing here is loaded by the game or read by `tools/pack-spritesheet.js` —
the packer only looks inside the folder you point it at, and nobody points it
here.
